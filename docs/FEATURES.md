# Features & Roadmap

## ✅ Current Features (MVP)

### User Management
- [x] User registration with email/password
- [x] User login and authentication
- [x] Profile creation with username
- [x] Profile customization (display name, bio, avatar)

### Link Management
- [x] Add unlimited links
- [x] Edit link title and URL
- [x] Delete links
- [x] Toggle link visibility (active/inactive)
- [x] Custom position ordering
- [x] Optional icons/emojis for links

### Profile Pages
- [x] Public profile pages (/:username)
- [x] Responsive design (mobile-first)
- [x] Fast page loading
- [x] Clean, modern UI

### Themes
- [x] 6 pre-built themes
  - Classic (white)
  - Dark Mode
  - Gradient (purple)
  - Minimalist
  - Pastel Dream (premium)
  - Ocean (premium)
- [x] Theme configuration (colors, button styles, fonts)

### Database & Backend
- [x] PostgreSQL database via Supabase
- [x] Row Level Security (RLS) policies
- [x] Real-time updates
- [x] Secure authentication
- [x] Avatar storage
